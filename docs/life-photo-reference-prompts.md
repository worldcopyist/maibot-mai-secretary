# Built-in life photo reference images

These two scene references were generated with the built-in imagegen tool. They contain no character and can be replaced by administrators in the installed plugin data directory.

## `assets/life_photo_home.png`

> Use case: illustration-story. Asset type: reusable background reference for a chatbot's optional life snapshot image generation. A single tidy lived-in apartment living room of a teenager living independently: small sofa, low table, potted plant, warm window light, casual books and a game controller. Cozy contemporary anime illustration, soft natural daylight, balanced midtones, clean shapes, believable domestic scale. Wide landscape view at eye level, no people, no animals, no posters with faces, no legible writing, no logos, no watermark. Keep furniture layout clear and reusable as a consistent location reference for future illustrations.

Wide landscape view at eye level, no people, no animals, no buildings with signs, no legible writing, no logos, no watermark.
